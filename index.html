Langkah 1: Siapkan API key Gemini gratismu

Situs ini memakai AI (Google Gemini) untuk Lab Simulasi Virtual dan Tutor Fisika. Masukkan API key Gemini milikmu sendiri dulu, gratis, tersimpan hanya di browser ini, dan tidak pernah dikirim ke siapa pun selain langsung ke Google.

  1. Buka Google AI Studio dan masuk dengan akun Google-mu.

    Buka aistudio.google.com/apikey

  2. Klik Create API key, lalu salin key yang muncul (diawali huruf AIza...).

  3. Tempel API key itu di kolom ini, lalu simpan.

Free tier Gemini punya batas kuota harian yang wajar untuk satu kelas, cek angka terbaru di ai.google.dev/gemini-api/docs/rate-limits. Jangan masukkan data pribadi ke dalam prompt simulasi.

Selamat datang di Physics Sandbox

Pilih topik di sebelah kiri untuk mulai belajar. Setiap topik punya empat bagian: Materi Belajar, Eksperimen, Latihan Soal, dan Lab Simulasi Virtual tempat kamu bisa membuat simulasi fisikamu sendiri dengan bantuan AI.
